## Usage

You should use this template to start your DevOps Capstone project. It contains all of the code that you will need to get started.

Do Not fork this code! It is meant to be used by pressing the  <span style=color:white;background:green>**Use this Template**</span> button in GitHub. This will copy the code to your own repository with no connection back to the original repository.

## Running the Application

In the root of the project, use the `make` command to run various tasks:

```bash
# Create and activate a Python virtual environment
$ make venv

# Install the dependencies
$ make install

# Run the tests
$ make test

# Start the service
$ make run

# Stop the service
$ make stop
```
